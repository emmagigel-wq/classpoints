# 班级积分系统

**版本：2.13.16**

班级积分系统是一个 Python 桌面应用。本仓库用于公开项目源码、构建说明和第三方组件许可信息。

## 获取源码

当前公开源码 ZIP 与仓库中的源码文件分开提供。源码 ZIP 不包含大型第三方 EXE。

## 第三方二进制组件

本项目使用两个用途不同的可选/辅助组件：

| 文件 | 用途 | 说明 |
|---|---|---|
| `ffmpeg.exe` | 视频/音频解码、媒体信息探测与视频转码 | 视频功能依赖；找不到时可通过应用下载组件或系统 PATH 提供 |
| `cloudflared.exe` | 建立 Cloudflare 公网隧道，让异网设备访问本机服务 | 主要用于跨网络访问；不是普通本地使用的必需组件 |

**这两个文件不是本项目原创代码，也不受根目录 MIT 许可证覆盖。** FFmpeg 恢复版本的构建参数包含 GPLv3 选项，当前尚未确认精确对应源码和构建材料，因此不随源码 ZIP 或本仓库公开再分发。cloudflared 使用 Apache 2.0 许可，应优先从 Cloudflare 官方发行渠道取得。

详细说明（包括文件查找位置、具体功能、版本线索、许可状态及上游地址）见：
[第三方二进制组件说明](docs/THIRD-PARTY-BINARIES.md)。
